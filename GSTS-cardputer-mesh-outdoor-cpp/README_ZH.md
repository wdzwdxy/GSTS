# Cardputer Mesh 户外应用 — 使用说明（中文）

本说明仅介绍**系统操作**与**系统设置**。硬件为 M5Stack Cardputer Mesh Kit (K152)，集成 GNSS（ATGM336H）与 LoRa（SX1262 / Meshtastic）。

---

## 一、系统操作

### 1. 开机载入画面
开机后先显示 **GSTS** 载入动画：四个字母依次淡入（约前 0.5 秒），停留完成硬件初始化后，自顶部向下卷帘擦除切入主界面，总时长约 2 秒。

### 2. 主界面（待机）
显示当前 GNSS 定位与系统状态：
- **纬度 / 经度**：标签在左、数值在右，横向排列。
- **高度 / 速度 / HDOP**：一行横向显示。
- 顶栏：录制状态（REC）、卫星数（SAT）、SD 卡状态、LoRa 状态（LR）、电量百分比。
- 无定位时显示"正在搜星…"。

### 3. 按键操作

| 按键 | 功能 | 说明 |
|------|------|------|
| **R** | 开始 / 停止轨迹记录 | 再次按下停止；文件名按本地时间（UTC+8）生成。 |
| **Fn + L** | 解锁 SOS | 先按 Fn 不放再按 L，进入"待触发"状态（屏幕顶部出现红条提示）。 |
| **S**（连按两下） | 触发 SOS | 必须在 Fn+L 解锁后 **2 秒内连按两下 S** 才生效；单独按 S 无效，防止误触。 |
| **ESC / `（反引号）** | 取消 SOS | 取消求救广播，同时解除已解锁状态；轨迹记录不中断。 |
| **T** | 轨迹全览页 开 / 关 | 切换纯矢量轨迹图（不加载地图）。 |
| **任意键** | 唤醒屏幕 | 息屏后按任意键唤醒（不执行该键动作）。 |

### 4. 屏幕与状态页

- **待机页**：显示定位与系统状态（见上）。
- **记录中页**：显示轨迹点数、里程、当前速度、高度，以及记录间隔与 GPX 文件路径。
- **轨迹全览页**：以矢量线条绘制已记录轨迹，起点（绿）/终点（红），右上角指北标记；底部显示点数、里程、范围（米）。轨迹点不足 2 个时提示"轨迹点不足"。
- **SOS 页**：红色闪烁背景，显示"正在救援频道循环广播…"、已发送次数、下次发送倒计时、当前坐标与卫星数；按 ESC 取消。

### 5. 省电（自动息屏）
- 非 SOS 模式下，**30 秒无按键**自动关闭背光息屏（GNSS / 记录 / LoRa 仍正常运行），按任意键唤醒。
- **SOS 模式强制常亮**，不息屏。

### 6. SOS 广播内容
在救援频道（Meshtastic 主信道，空 PSK 不加密）循环广播，默认每 15 秒一次：
- 有定位时：`TEXT` 文本报文与 `POSITION` 位置图钉报文交替广播（对方 stock Meshtastic 节点可直接显示位置）。
- 无定位时：仅发 TEXT 文本求救报文。

### 7. 轨迹记录输出
轨迹以 **GPX 1.1** 格式实时写入 microSD 卡，文件路径如 `/track_YYYYMMDD_HHMM.gpx`，每个点写入后文件始终保持合法 GPX，可直接导入地图软件。

## 二、系统设置（config.h）

所有可调参数集中在 `src/config.h`，修改后重新编译烧录生效。

### 轨迹与 GNSS
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `RECORD_INTERVAL_S` | `5` | 每隔多少秒记录一个定位点。 |
| `GNSS_BAUD` | `115200` | GNSS 串口波特率（无数据可尝试 9600）。 |
| `GNSS_RX_PIN` / `GNSS_TX_PIN` | `15` / `13` | ESP32 与 GNSS 的串口引脚。 |

### SPI / LoRa 硬件引脚
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `PIN_SPI_SCK` / `PIN_SPI_MISO` / `PIN_SPI_MOSI` | `40` / `39` / `14` | 共享 SPI 总线引脚（LoRa 与 SD）。 |
| `PIN_SD_CS` | `12` | SD 卡片选。 |
| `PIN_LORA_NSS` / `PIN_LORA_DIO1` / `PIN_LORA_RST` / `PIN_LORA_BUSY` | `5` / `4` / `3` / `6` | SX1262 控制引脚。 |
| `IOE_I2C_ADDR` | `0x43` | 天线开关 IO 扩展芯片地址（P0 拉高接通天线）。 |

### LoRa / Meshtastic（CN 区域）
> `LORA_FREQ` 必须与你的 stock Meshtastic 节点一致（参考 `meshtastic --info` 的 Freq）。CN 公式：`470.0 + slot*0.125` MHz。

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `LORA_FREQ` | `470.125f` | 频段频率（MHz，默认 slot=1，按实际修改）。 |
| `LORA_BW` | `250.0f` | 带宽（kHz，CN LONG_FAST）。 |
| `LORA_SF` | `11` | 扩频因子。 |
| `LORA_CR` | `5` | 编码率（4/5）。 |
| `LORA_POWER` | `17` | 发射功率（dBm，CN 上限 19）。 |
| `LORA_PREAMBLE` | `16` | 前导码长度（Meshtastic 固定 16）。 |
| `LORA_SYNCWORD` | `0x2B` | 同步字（Meshtastic，SX126x 展开为 0x24B4）。 |

### 本机身份 / SOS
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `MY_NODE_ID` | `0x11223344UL` | 自定义 32 位节点号（非零）。 |
| `CHANNEL_INDEX` | `0` | 信道索引（0 = 主信道空 PSK 救援频道）。 |
| `SOS_INTERVAL_S` | `15` | SOS 循环发送间隔（秒）。 |
| `SOS_HOP_LIMIT` | `5` | 最大转发跳数。 |
| `SOS_TEXT` | `"SOS! Need rescue 需要救援"` | SOS 文本报文内容。 |

### SOS 防误触（两段式触发）
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SOS_ARM_TIMEOUT_MS` | `5000` | Fn+L 解锁后无操作自动重新上锁的时限（毫秒）。 |
| `SOS_DOUBLE_MS` | `800` | 两次按 S 之间的最大间隔（毫秒），超时重新计数。 |

### 省电（自动息屏）
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SCREEN_BRIGHTNESS` | `80` | 正常背光亮度（0–255）。 |
| `SCREEN_OFF_MS` | `30000` | 无按键自动息屏时间（毫秒）；SOS 模式强制常亮。 | |
